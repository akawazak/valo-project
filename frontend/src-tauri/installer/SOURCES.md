# Installer artwork

`installer-hero.bmp` is a cropped, framed installer asset derived from the Omen artwork already included at `frontend/public/themes/omen-outlaw.jpg`.

That source wallpaper comes from Riot Games' official [VALORANT Media](https://playvalorant.com/en-us/media/) packs. It is used here only to present VantaVault's VALORANT companion installer and does not imply endorsement by Riot Games.
