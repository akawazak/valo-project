# Working Guidelines

## Focused mode

- Inspect only files directly involved in the requested flow.
- Do not load optional skills unless strictly required.
- Avoid broad repository searches and large command outputs.
- Use targeted tests first; run full builds only before committing or when risk requires them.
- Do not generate concepts, mockups, screenshots, reports, or documentation unless explicitly requested.
- Send minimal progress updates.
- Stop after the requested result is implemented and verified.
- If the task expands beyond the original scope, ask before continuing.
- Preserve root-cause fixes and regression tests; reduce investigation overhead, not correctness.
