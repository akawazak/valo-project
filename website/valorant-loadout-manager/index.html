BUILT FOR COMPLETE SETUPS

One change should not require six different screens.

01

See what is equipped now

The loadout opens with your current identity and weapon cosmetics already visible. Each slot works directly; it is not a shortcut that sends you somewhere else first.

02

Choose from what you own

Cosmetic pickers prioritize readable artwork and owned content, with search available when useful instead of automatically taking focus every time a picker opens.

03

Save coherent presets

Presets can hold a complete look rather than a loose list of skins. Applying one updates the selected groups together and keeps effective Riot loadout identifiers intact.

04

Account-aware application

Before a loadout change is applied, VantaVault makes the selected local account clear so an open game account and a stored account are not silently mixed.

Changes use supported client services

VantaVault does not modify game files or inject code. Loadout changes use authenticated Riot client services and may depend on the account being available through the supported Windows session.
