CURRENT STATE, NOT A STATIC CARD

The home screen should know whether you are actually playing.

01

Party state on the home screen

Party membership, leadership, readiness, queue, and matchmaking time appear where you need them. The panel is not a shortcut to another page; it updates in place.

02

Agent select at the right moment

When a pre-game session exists, VantaVault can show the map, queue, teammates, agent choices, and timer. Outside agent select, the interface does not pretend the data is live.

03

Useful live-match context

Supported matches can include team composition, competitive context, party evidence, recent form, and live score information with clear loading and unavailable states.

04

Presence beyond VALORANT

The social list can separate friends in VALORANT, League of Legends, another Riot title, the Riot Client, online, and offline instead of flattening every activity into one broad status.

Live data is conditional by design

Presence and match endpoints can depend on Riot client availability, region, authentication mode, game phase, and service health. VantaVault shows detailed errors and stale-state labels rather than reporting a connection it cannot confirm.
