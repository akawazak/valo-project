DATA HANDLING

Clear boundaries for what is stored and why.

01

Authentication sessions

When you authenticate through a Riot web flow, the resulting browser session is kept in a local WebView2 profile associated with that account. VantaVault does not operate a cloud account database for these sessions.

02

Match and content cache

Match records and public content metadata can be cached locally so screens appear quickly and short network failures do not erase information you already retrieved. Retention controls determine how long history stays.

03

Diagnostics without tokens

Error exports are designed to include useful request context and error codes while excluding authentication tokens. You should still review diagnostic files before sharing them publicly.

04

Website measurement

This website uses Vercel Web Analytics and Speed Insights to measure page visits and performance. It does not run advertising trackers or create a VantaVault account. Downloads are hosted and counted by GitHub Releases.

05

Uninstalling and deleting data

The app is portable, while WebView2 sessions and application data may live in the local data directory. Use the app's account and storage controls to remove stored sessions and history before deleting the executable.

Riot service boundaries still apply

VantaVault depends on Riot authentication and services that can change or become unavailable. It is not endorsed by Riot Games, does not bypass account permissions, and cannot make unavailable account data public.
