MORE THAN A SCORELINE

Profiles should answer the next question, too.

01

Rank in its act context

The profile keeps your current competitive standing, peak rank, placement state, and act progression together. Rank art comes from the game content catalog rather than generic substitutes.

02

Automatic match retrieval

VantaVault requests recent matches at sensible moments and caches the result locally. Manual sync remains available as a recovery tool, not a required first step for every profile.

03

Readable match rows

Each result can show map art, queue, agent, score, party context, time played, and rank movement so a missing agent portrait or vague row does not hide the actual match.

04

History that survives short API gaps

Previously retrieved matches can stay on the PC according to your retention setting. The interface can show cached information immediately and refresh it in the background.

Availability follows Riot data

Some profile, rank, or match fields may be unavailable for a platform, queue, region, or privacy state. VantaVault labels missing data and cached data instead of inventing values.
